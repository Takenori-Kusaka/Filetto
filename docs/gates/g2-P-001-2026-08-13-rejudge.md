## ★再判定の対象 — 範囲を変えた変更は2件です

### 変更A: F-002 のスコープ外を狭めた

**「文字がほとんど無い図・グラフ画像からの内容取得」を、スコープ外から外しました。**

**前回の判定で、あなたはこれをスコープ外として承認しています。**

**根拠が崩れました。**

| | Docling 経由 | RapidOCR 直接 |
| --- | --- | --- |
| `fig-kakei-02.png` の抽出文字数 | 23 | **394**(17.1倍) |
| 正解に必要な文字列 | 0/9 | **9/9** |

**「文字がほとんど無い図」と判定していましたが、表題・軸目盛・注釈がすべて描かれていました。** 取れなかった原因は画像ではなく、**Docling が図領域内の文字を捨てていたこと**です。技術報告が明記しています(`arXiv:2408.09869v5`: "Text content inside figures is currently dropped")。

**加わった受入基準は3件です。**

| 基準 | 内容 |
| --- | --- |
| **7-2** | 図が大きな面積を占める画像は、**Docling を介さず RapidOCR を直接呼ぶ経路でも抽出し、文字数が多いほうを採用する** |
| 13-2 | 抽出テキストの Unicode confusables を検出し、派生物メタデータへ記録する |
| 13-3 | **confusables を自動で置換してはならない** |

**ページ画像の保存は引き続き行いません**(基準6 は維持)。

**「原文どおりの文字列を保証すること」はスコープ外のままです。** confusables の検出を加えても、**漢字同士の字形近似(`日`→`目`)は設計上の対象外のため拾えません。**

### 変更B: F-003 の認可を、既定で適用しないことにした

**これが本再判定で最も重い変更です。**

**前回の判定時、F-003 の認可は「JWT が無ければ 401」でした。無条件です。**

**PO が申告した欠陥1(JWT 無しは401 + JWT を発行しない + Auth は後続開発 が同時に成立しない)への対応です。** 初版を `docker compose up` で起動した利用者は JWT を発行する主体を持たず、**すべての要求が 401 になります。**

**加わった受入基準は6件です。**

| 基準 | 内容 |
| --- | --- |
| **29** | **認可の適用の有無を環境変数から読み取り、既定値を「適用しない」とする** |
| 30 | JWT の署名検証に**非対称鍵の公開鍵のみ**を用い、HS* と `alg: none` を受理しない |
| 31 | 検証に用いる公開鍵を環境変数から読み取る |
| 32 | スコープの解決に、JWT のクレームとローカルポリシーの両方を用いる |
| 33 | ローカルポリシーの保管先を環境変数から読み取り、定数として持たない |
| 34 | 認可が有効なとき、判定に用いたローカルポリシーの版を監査ログへ記録する |

**既存の 24〜27 は、番号も意味も変えていません。** 24・25 に条件節「認可の適用が有効な状態で」を足しただけです。

**判断していただきたいのはここです。**

> **既定で認可を適用しない、という状態で公開してよいか。**

**意味するもの**

| # | 内容 |
| --- | --- |
| 1 | **既定の構成では、誰でも全ファイルを読める。** localhost バインドが前提 |
| 2 | 利用者が環境変数で明示的に有効化したときだけ、認可が働く |
| 3 | **有効にした場合、鍵は利用者が用意する**(Filetto は JWT を発行しない、基準27 は維持) |

**採らなかった案**

| 案 | 内容 | 退けた理由 |
| --- | --- | --- |
| ア | 利用者が自分で JWT を作り、環境変数で与える | **利用者に鍵管理を課す**([[calm-technology]] と緊張) |
| ウ | 「発行しない」を「利用者向けの認証情報の発行を行わない」と読み替える | 基準27 の改訂が要る |
| エ | 初版では認可を実装せず、Auth の合成時に導入する | **ADR-0003 と衝突**。ゴミ箱が権限の緩い経路から読める |

**PO は方向イ(既定で適用しない)を [#55](https://github.com/Takenori-Kusaka/Filetto/issues/55) で判断済みです。本再判定はその追認を求めるものです。**
