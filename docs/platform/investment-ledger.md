# 投入量の台帳

**標準 7.7.2 が定める予算統制の指標を計算するための実測を、時系列で残します**([#107](https://github.com/Takenori-Kusaka/Filetto/issues/107))。

| 指標 | 定義 |
| --- | --- |
| 予算消化率 | 消化した予算 ÷ 配賦した予算 |
| **消化進捗比** | **予算消化率 ÷ 進捗率。1を超えるほど計画より費用が先行している** |
| AI実行予算の消化率 | 月次の実消費 ÷ 月次の配賦額 |

## 誰も自己申告しません

**ロールに主目的以外の作業をさせません。** 稼働時間の記入も、費用の報告も求めません。**すべて git・GitHub・既存の OSS から機械が出します。**

**確度は高くありません。** 稼働時間はコミット間隔からの推定であり、実際に机に向かっていた時間ではありません。**値そのものではなく推移を見ます。** 完璧なデータを待つと、記録が1件も残らないまま案件が終わります。

## 測り方

```bash
node scripts/gate/investment-measure.mjs --markdown
```

| # | 項目 | 取り方 | 確度 |
| --- | --- | --- | --- |
| 1 | **AI 実行費(金額)** | **[ccusage](https://github.com/ccusage/ccusage)**(OSS)。`~/.claude` のセッション記録から LiteLLM の価格で算定する | 中 |
| 2 | 出力トークン | 同上 | 高 |
| 3 | **稼働時間** | **git のコミット間隔からの推定**。既定は「間隔が120分未満なら加算、超えたら30分とみなす」 | **低** |
| 4 | セッションが動いていた実時間 | ccusage の活動時刻。5つの作業ツリーは同時に動くため、**重なりを潰した値** | 低 |
| 5 | マージ済み PR の分類 | `gh pr list --json files` と `investment-classes.json` の規則 | 高 |
| 6 | 行数 | 作業ツリーの走査 | 高 |
| 7 | 進捗の代理指標 | 判定記録のあるゲート数・実装計画のある機能数 | **代理**。進捗そのものではない |

**AI 実行費の価格表を自前で持ちません。** ccusage が持っています。価格は変わるため、自前で持つと更新が止まった時点で誤った金額を出し続けます。

**1・2・4 は `~/.claude` を読むため CI では取れません。** CI は 3・5・6・7 だけを出し、AI 実行費は「取得できません」と明示します。**黙って 0 円として記録しません。**

### 分類規則

`scripts/gate/investment-classes.json` にあります。**一致しないファイルがあると失敗します。** 規則を増やさずに新しい領域が増えると、内訳が実態とずれたまま「測った」記録が残るためです。

### 読み取れること

**ゲートは半分まで進み、実装コードは11行です。**

**AI 実行費 $652.35 のうち、PO の作業ツリーが $432.34(66%)を占めます。** 判断と記録の往復に費用が寄っています。

**消化進捗比は計算できません。** 予算の配賦額が決まっていないためです。**代理指標として「ゲート1つあたりの AI 実行費 $163.09」を置きます。** 残り4ゲートに同額かかるなら、あと $652 で G-8 に届く計算になります。**この外挿は実装が0行である事実を織り込んでいません。**

### #107 の手集計との差

| 区分 | #107(手) | 本台帳(機械) | 差の理由 |
| --- | --- | --- | --- |
| 稼働時間 | 12時間 | **17.5時間** | 手集計は体感。機械はコミット間隔からの推定 |
| AI 実行費 | 推定20万円 | **$652.35(約9.8万円)** | 手集計は週間トークン枠の消費割合から逆算。機械は LiteLLM の従量価格 |
| プロセス | 37件(58%) | 24件(36%) | **手集計は「プロセス系 ADR」を広く採った。** 機械は `investment-classes.json` に列挙した6本の ADR だけをプロセスとする |
| プロダクト | 20件(31%) | 36件(54%) | 同上の裏返し |
| ゲート記録 | 6件(9%) | 6件(9%) | 一致 |
| 実装コード | 1件 | 1件 | 一致 |

**AI 実行費の差は契約形態の違いです。** 定額枠を使っている場合、従量価格での算定額は「同じ量を従量で買ったらいくらか」であり、実際の支払額ではありません。**どちらも投入量の代理です。**

**「プロセス自身の整備コストがどの予算区分にも属していない」という [process-compass#240](https://github.com/Takenori-Kusaka/process-compass/issues/240) の論点3 は、どちらの数え方でも成立します。**
