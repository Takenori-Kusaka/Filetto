# PL-0008: spec-lint の適用範囲に「引用」を加える

対象 Issue: [#104](https://github.com/Takenori-Kusaka/Filetto/issues/104) 追加依頼
作成: 2026-08-14 / レーン: Platform

## 1. 何を直したか

**行頭 `>` の引用ブロックを、既定で検査から外します。**

**閣議決定文書の条文や調査票の選択肢は、こちらの都合で書き換えられません。** 書き換えると引用が原文と一致しなくなります。

| 変更 | 内容 |
| --- | --- |
| `scripts/gate/spec-lint-policy.json`(新規) | 禁止語と方針。**運用に依存する値を検査の定数にしません** |
| `scripts/gate/spec-lint.mjs` | 引用ブロックの除外。**外した行を件数とファイル名とともに出力する** |
| `tests/gate/test_spec_lint.py` | 検証7件を追加(否定側3件) |

## 2. `specs/` の配下では引用も検査します

**引用の形にすれば禁止語を書ける、という抜け道を作りません。**

```json
"quoteBlock": {
  "exempt": true,
  "enforcedPaths": ["specs/**"]
}
```

**`specs/` は受入基準の正本です。** そこで一次資料を逐語引用する場面は想定していません。**引用が要るなら、区間の除外(`spec-lint-ignore`)で理由とともに書きます。**

## 3. 表のセル内は、区間で囲みます

**依頼のもう1つ「表のセル内で、出典を伴う逐語引用と明示された箇所」は、パターンでの判定を入れませんでした。**

**「出典を伴う」ことを機械が判定できないためです。** 出典らしき文字列の有無で判定すると、誤除外と誤検出の両方が増えます。**検査の確度を下げる方向の変更になります。**

**既存の区間の除外で足ります。**

```markdown
<!-- spec-lint-ignore start: 調査票の選択肢の全文の逐語引用。原文を書き換えると引用が原典と一致しなくなる -->
| 選択肢 | 回答率 |
| --- | --- |
| 社内情報の漏洩などのセキュリティリスクがある | 42% |
<!-- spec-lint-ignore end -->
```

**理由が残り、出力に現れます。** 引用ブロックの除外と同じ性質のものが、同じ形で記録されます。

## 4. 外した行は必ず出力します

```
引用ブロックとして検査から外した行: 1 行(1 ファイル)
  docs/spikes/S0-010-barrier-decomposition.md
  specs/** の配下では引用も検査します
```

**0行のときも「0行」と出します。** 除外が広がっていくことが出力に現れます。

## 5. 禁止語が0語なら落とします

**方針をファイルへ出したことで、「禁止語を空にする」という抜け道ができました。** 空のまま通すと、検査を実施していない状態を通過した記録として残ります。**0語は落とします。**

## 6. 検証

```
$ node scripts/gate/spec-lint.mjs   → 54 ファイルを検査、0 件検出
$ pytest tests/gate                 → 74 passed
$ ruff check .                      → All checks passed!
```

| # | 確かめたこと | 結果 |
| --- | --- | --- |
| 1 | 引用ブロックは検査しない | 通った |
| 2 | **引用として外した行を必ず出力する** | 出た |
| 3 | 引用が0行でも件数を出力する | 出た |
| 4 | **引用の外は検査する** | 落ちた |
| 5 | **`specs/` 配下では引用も検査する**(同時に `docs/` の引用は外れる) | 落ちた |
| 6 | 方針が禁止語と引用の扱いを持つ | 通った |
| 7 | **禁止語が0語なら落ちる** | 落ちた |

**5 は1回の実行で両方を確かめています。** `specs/F-999/spec.md:1` が落ち、`docs/spike.md` は「外した行1行」として数えられます。

## 7. 既存の区間の除外について

**PR #116 で `docs/spikes/` の7件は、既に区間の除外で回避されています。** 本変更でそれらは重複しますが、**害はありません**(区間が先に効きます)。

**今後の調査記録では、引用ブロックに区間を書く必要はありません。**
