# S0-009 政府の AX 政策に、本製品が位置づくかを確かめる

事業決裁者の指摘により実施しました。

> **今年の日本政府の骨太方針に AX(AI Transformation)というキーワードが初出しました。**(中略)**日本政府はこの AX に多くの投資予算を割り振ることを決めており、経営層としてそこに貢献できる可能性のあるものを事業ポテンシャルとして高く見積もる可能性が高いためです**

**一次情報(閣議決定文書の PDF 原文)を取得し、全文検索で確認しました。**

**注意**: 政府文書は全角の「ＡＸ」表記です。半角で検索すると0件になります。

## 結論を先に

**AX は実在の政策概念であり、閣議決定文書に定義があります。予算も前年比2.55倍に伸びています。**

**しかし、本製品を位置づける根拠にはなりません。**

| # | 理由 |
| --- | --- |
| **1** | **予算の91%(4,559億円/5,027億円)は「AIを創る」側。「AIを使う」は438億円** |
| **2** | **オンプレミス／ローカル完結は政府文書に事実上存在しない。唯一の言及は「オンプレを刷新してクラウドへ移行する」という逆向き** |
| **3** | **政府が求めるのは「外に出さない」ではなく「国外に出さない／国内で完結」。国産クラウドで要件を満たす整理** |
| **4** | **自治体・行政向けの文書 RAG は、デジタル庁が「源内」を OSS 公開して自ら供給する方針** |

**「政府が AX に巨額を投じており、その周辺市場が立ち上がる」という市場環境の説明としては使えます。**

**「政府が本製品のようなものを必要としている」という需要の論証には使えません。**

## 1. AX の定義と初出

### 「骨太方針に初出」は、厳密には不正確

| 文書 | 閣議決定日 | ＡＸ出現数 |
| --- | --- | --- |
| **人工知能基本計画(改定)** | **令和8年7月14日** | **24回** |
| 経済財政運営と改革の基本方針2026 | 令和8年7月21日 | 9回 |
| デジタル社会の実現に向けた重点計画 | 令和8年7月21日 | 多数 |
| 骨太方針2025 | 令和7年6月13日 | **0回** |
| 人工知能基本計画(初版) | 令和7年12月23日 | **0回** |

**骨太2025 の「ＡＸ」1件は「ＪＡＸＡ」の部分一致でした。**

**AX は骨太シリーズでは骨太2026 が初出ですが、政府文書全体では人工知能基本計画の改定(7月14日)が7日早いです。**

**同計画の副題自体が「〜日本ＡＸ、より強く、より豊かに〜」であり、AX の本拠地は骨太ではなく AI 基本計画です。**

### 定義文(逐語引用)

**最も明確な定義**は、デジタル庁「重点計画」参考資料の脚注です。

> ※あらゆる組織で、AIを前提として意思決定や業務の進め方を根底から見直すこと。

**人工知能基本計画(令和8年7月14日 閣議決定)の本文**

> 我が国として、バーティカルＡＩやフィジカルＡＩで現場力を一層強化し、産業や行政、国民生活の課題を解決、国力を強化するため、**あらゆる組織で、ＡＩを前提として意思決定や業務の進め方を根底から見直す「ＡＩトランスフォーメーション(ＡＸ)」を進めていく**。社会全体でＡＸに取り組むことを前提に、人とＡＩの協働の在り方や、規制及び制度を再設計していかなければならない。

**骨太方針2026(令和8年7月21日 閣議決定)**

> 両者を貫く成長の加速装置として、豊富な現場データやものづくり基盤等の我が国の強みを最大限に活かした**フィジカルＡＩの構築を軸とする「ＡＩトランスフォーメーション(ＡＸ)」を全産業で加速**し、人口減少下においても高付加価値を生み出す経済構造への転換を図る。

**正確な表記は全角の「ＡＩトランスフォーメーション(ＡＸ)」です。**

### DX との関係 — 置換ではなく積層

**ほぼ常に「ＡＸ／ＤＸ」と併記されます。**

> 人口減少に対応するため、政府における**これまでのDX基盤の整備を踏まえ**、国、自治体はもとより社会全体で生成AI及びAIエージェント等を活用する「AX/DX」を推進する

**DX 基盤(ガバメントクラウド・標準化)が下、AX がその上という構造です。**

## 2. 予算 — 伸びは本物。ただし配分が決定的

**内閣府 AI戦略ページ(`https://www8.cao.go.jp/cstp/ai/`)の一次資料。**

| 年度 | 区分 | AI 関連予算 |
| --- | --- | --- |
| **令和8年度** | 当初 | **約5,027億円** |
| 令和7年度 | 当初 | 約1,969億円 |
| 令和7年度 | 補正 | 約4,380億円 |
| 令和6年度 | 当初 | 約1,176億円 |

**令和8年度当初は前年比 約2.55倍です。**

### しかし内訳が決定的

| AI 基本計画の4方針 | 令和8年度当初 | 割合 |
| --- | --- | --- |
| **2. AI開発力の戦略的強化「AIを創る」** | **4,559億円** | **91%** |
| **1. AI利活用の抜本的な推進「AIを使う」** | **438億円** | **8.7%** |
| 4. AI社会に向けた継続的な変革「AIと協働する」 | 19億円 | 0.4% |
| 3. AIガバナンスの主導「AIの信頼性を高める」 | 11億円 | 0.2% |

**しかも「創る」の大半が単一事業です。**

> ・ＡＩロボット・フィジカルＡＩを見据えたマルチモーダル基盤モデルの開発[新](経: **3,873億円**)

**「使う」は438億円にすぎず、そこに文書検索基盤への言及はありません。**

## 3. AX の実現に必要とされている要素

| 論点 | 該当 | 備考 |
| --- | --- | --- |
| データ利活用基盤 | **あり(強い)** | データスペース技術・国内プラットフォームの育成 |
| **中小企業への普及** | **あり(強い)** | **「地域ＡＸ」として独立項目化** |
| セキュリティ・データ主権 | **部分的** | **「データ主権」の語は0件。「ＡＩ主権」はある** |
| **オンプレミス／ローカル** | **実質なし(むしろ逆風)** | 後述 |
| 文書・非構造化データ | **語としては0件。ただし極めて近い一文あり** | 後述 |

### 中小企業への普及 — あり

**人工知能基本計画 第1節(2)⑤**

> **地域ＡＸの推進**のため、**大規模成長投資補助金やデジタル化・ＡＩ導入補助金**を始めとする中堅・中小企業におけるＡＩ導入に加え、中小企業がＡＸを推進するための地域ごとのネットワーク構築や伴走支援を行う支援機関のＡＩ支援レベルの底上げを支援する

**骨太2026**

> 地域の中堅・中核企業におけるＡＩ導入を進め、**地域ＡＸを推進する**

### 最も近い一文 — 完全な構造化をしない現場データ

**人工知能基本計画 第1節(3)③**

> ③ **データ利活用の第一歩として、完全なデータの構造化をしない形での現場データの活用を推進する。医療、教育、農林水産業、建設等の準公共分野**や、日本の強みとなる産業・研究分野における豊富で質の高いデータを日本の勝ち筋として活かし、**営業秘密の流出リスク対応など、データの安全性の確保を図った上で**、データ連携基盤を構築する

**「完全な構造化をしない現場データの活用」＋「医療等の準公共分野」＋「営業秘密の流出リスク対応」が一文に同居しています。**

**政府文書上、本製品に最も近い記述です。**

**ただしこれは方向性の一致であって、政府がその実現手段としてローカル完結型の製品を求めているという記述ではありません。**

## 4. オンプレミス／ローカル — 該当なし。むしろ逆風

| 文書 | 「オンプレ」 | 「ローカル」 |
| --- | --- | --- |
| 骨太2026 | **0件** | AI 文脈での用例なし |
| 人工知能基本計画 | **0件** | **0件** |
| 重点計画(190ページ) | **1件のみ** | — |

**その唯一の1件が、逆向きの記述です。**

> 病院の情報システムについては(中略)生成AI など最新技術を活用しやすくするため、**現在のオンプレ型のシステムを刷新し、モダン技術を活用したクラウド型システムに移行していくことを目指す**

**医療分野において、政府方針は明確に「オンプレ → クラウド」です。**

**骨太2026 の62の主要製品・技術リストにも「クラウドネイティブに最適化された医療ＤＸ基盤」と明記されています。**

### 政府が求めているのは「国外に出さない」であって「外に出さない」ではない

**「データ主権」は全文書で0件です。** 代わりに「ＡＩ主権(AI Sovereignty)」が使われます。

**人工知能基本計画**

> **営業秘密等の機微情報の国外への流出リスク対応など我が国のデータの安全性を確保する**ことを含めて、戦略的に推進する

**重点計画**

> 基幹的な行政サービスであって常時稼働が必要なAI モデルを含むデジタル基盤については(中略)**国内で完結可能であることが望ましい**

**国産クラウドで要件を満たす整理になっており、ローカル完結の必然性を政府文書からは導けません。**

**これは [S0-008](./S0-008-demand-hypothesis.md) の弁護士会の結論(クラウドで足りる)と同じ方向です。**

## 5. 既に手当てされつつある — 最大の逆風

### ガバメントAI「源内」

**重点計画**

> 令和7年度にデジタル庁が**内製開発した生成AI 利用環境「源内」**について、令和8年度は**全府省庁対象の実証事業**を着実に推進し(中略)令和9年度以降の本格利用開始を検討する

**人工知能基本計画**

> 「源内」の**オープンソース化の取組を通じて自治体のＡＩ導入支援を進める**【◎デジタル庁、全省庁】

**二次情報**(デジタル庁ニュース。一次で裏取りできていない)では、2026年4月24日に OSS として公開済み、**RAG 機能を実装**し「行政資料RAGアプリ」を展開、法令の逐条解説・申請マニュアル等の知識ベースを接続、令和8年度に全府省庁約18万人規模の実証、とされています。GitHub: `digital-go-jp/genai-web`。

### さらに、政府が OSPO を設置する

**重点計画は、デジタル庁に OSPO(オープンソース・プログラム・オフィス)を令和8年度早期に政府初設置し、標準ソフトウェアを OSS として公開する方針を定めています。**

**含意**: **「自治体・行政向けの文書 RAG 基盤」は、政府が自ら OSS で無償供給する領域になりつつあります。**

**ここを主戦場に据えると、競合は民間ではなくデジタル庁です。**

**ただし**: 源内はガバメントクラウド上での提供であり、**オンプレミス提供の記載は確認できませんでした。** また対象は行政機関であり、**医療機関・法律事務所・士業事務所は源内の射程外です。**

## 6. 補助金 — OSS が対象になるかは確認できず

**人工知能基本計画が名指しする中小企業向け支援**

- **デジタル化・ＡＩ導入補助金**(正式名称: 中小企業デジタル化・AI導入支援事業費補助金、旧 IT導入補助金)
- **大規模成長投資補助金**

**申請枠に「通常枠」「インボイス枠」「セキュリティ対策推進枠」「複数者連携デジタル化・AI導入枠」があることは確認しました。**

**OSS や自社開発ソフトが補助対象になるかは、公募要領に当たれておらず確認できていません。**

**旧 IT導入補助金は「事務局に登録された IT導入支援事業者が登録した ITツール」を対象とする方式であり、OSS 単体では対象外である可能性がありますが、これは未検証の推定です。根拠として使いません。**

## 7. 判定 — 弱い

**役員決裁資料に「本製品は AX の部品として政府文書に位置づく」と書ける根拠はありません。**

### 書けること(一次情報で裏付け済み)

| # | 内容 |
| --- | --- |
| 1 | **AX は実在の政策概念であり、閣議決定文書に定義がある**(令和8年7月) |
| 2 | **AI 関連予算は令和8年度当初 5,027億円、前年比2.55倍** |
| 3 | **「地域ＡＸ」として中小企業への普及が独立項目化**され、補助金が名指しされている |
| 4 | **「完全なデータの構造化をしない形での現場データの活用」を、医療・教育・建設等の準公共分野で推進**すると明記 |
| 5 | **「営業秘密等の機微情報の国外への流出リスク対応」が計画本文にある** |
| 6 | 骨太2026 の62の主要製品・技術に「セキュリティの確保された政府・地方公共団体のＡＸ/ＤＸ基盤」が含まれる |

### 書けないこと

| # | 内容 |
| --- | --- |
| **1** | **予算の91%は「AIを創る」。うち3,873億円は単一のマルチモーダル基盤モデル開発事業。「AIを使う」は438億円** |
| **2** | **オンプレミス／ローカル完結は政府文書に事実上存在しない。唯一の言及は逆向き** |
| 3 | **「データ主権」「非構造化データ」「RAG」「文書検索」は、骨太・AI 基本計画のいずれにも0件** |
| **4** | **自治体・行政向けの文書 RAG は、デジタル庁が「源内」を OSS 公開して自ら供給する方針** |
| **5** | **政府が求めるのは「外に出さない」ではなく「国外に出さない／国内で完結」** |

### 推奨する扱い

**「政府が AX に巨額を投じており、その周辺市場が立ち上がる」という市場環境の説明としては使えます。**

**「政府が本製品のようなものを必要としている」という需要の論証には使えません。**

**決裁資料では「政策の方向性と整合する」までに留め、根拠の強度を偽らないこととします。**
