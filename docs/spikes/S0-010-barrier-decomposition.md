# S0-010「使い方がわからない」を分解する

[S0-008](./S0-008-demand-hypothesis.md) で、性質の異なる3つの調査が「導入しない理由の首位」として同じ結論に収束することが判明しました。

**しかし「わからない」が具体的に何を指すのかが不明のままでした。本書はそれを分解します。**

**事業決裁者の指摘が起点です。**

> **エクスプローラ思想がそこに訴求する可能性ってありそうですか？**(中略)**それよりもっと根本的なレベルでの不透明感がありますか？ 本質的な使い方の不明は何でしょうか**

## 結論を先に

**障壁は「操作の学習コスト」ではありませんでした。**

**データが指し示すのは、信頼コストと組織コストです。**

| 順 | 障壁 | 実測 |
| --- | --- | --- |
| **1** | **出力を信じてよいかわからない** | **IPA 日本 40.5% 対 米独 19.6%。全10項目中で国際差が最大** |
| 2 | 効果が読めない | IPA 48.6%(首位) |
| 3 | 使ってよい範囲がわからない | IPA 37.8%(日本首位) |
| 4 | 用途・業務との接続 | IPA 25.9%。**ただし自治体では3年で21%減。減衰中** |
| **—** | **操作がわからない** | **企業向け3調査すべてで、選択肢として提示すらされていない** |

**そして「エクスプローラ思想が学習コストを下げる」という仮説は、反証されたのではなく未検証です。**

**測定されていないものを「障壁ではない」と結論することはできません。**

## 4. 「エクスプローラ思想が学習コストを下げる」仮説の評価

**この仮説に、一次情報の裏付けは付きませんでした。3段階に分けて述べます。**

### 4-1. 積極的な反証ではない

**企業向け3調査で「操作」が低く出ているのではありません。そもそも選択肢に無いためです。**

**回答者は「操作が難しい」と答えたくても答えられませんでした。**

**「操作は障壁ではない」と結論するのは、測定していないものを否定することになり、成立しません。**

### 4-2. しかし間接証拠は不利

**「操作」の代理指標が唯一提示されている自治体調査で、「生成AIの技術を理解することが難しい」は 199件・14項目中10位です。**

**首位の「正確性への懸念」608件の3分の1未満です。**

**選択肢として与えられた場でも、操作理解は上位に来ていません。**

### 4-3. 唯一の支持材料は、解釈に依存する

**個人非利用者の「使い方がわからない」38.6%(独の2.1倍)は、操作を含む可能性があります。**

**しかしこれは分解されておらず、原調査の執筆者自身は「便利な使い方が周知されていく」と用途方向に読んでいます。**

**この 38.6% を操作の根拠として引用するのは、一次情報の解釈を著者の解釈に反する方向へ拡張することになります。**

### 結論

**仮説は「反証された」のではなく「未検証」です。**

**検証するには、既存統計の再解釈ではなく、「操作が難しい／プロンプトが書けない」を独立した選択肢として提示した自前の調査か、被験者実験が要ります。**

## 5. より根本的な障壁

**データが指し示すのは、学習コストではなく信頼コストと組織コストです。**

### 5-1. 出力の正確性への不信 — 日本に固有の突出

**IPA で日本 40.5% 対 米独 19.6%。**

**この2倍差は図表2-12 の全10項目で最大であり、日本固有の症状はここです。**

**自治体でも首位かつ3年で増加しています(562→608)。**

**「学習が済んだ人ほど、この障壁に当たる」という構造が経年データに出ています。**

### 5-2. 規模による断絶 — 国際差より大きい

| | 「関心のみ + 予定なし」 |
| --- | --- |
| **日本 100人以下** | **79.2%** |
| 米国 100人以下 | 22.3% |
| ドイツ 100人以下 | 35.6% |
| 日本 1,001人以上 | 10.1% |

**日本国内の規模差(79.2% 対 10.1%)が、国際差より大きいです。**

### 5-3. ルールが作れない

**IPA 37.8%(日本首位)。**

**これは製品の UI では解けず、ガバナンス設計の問題です。**

### 5-4. 用途の障壁は減衰中である

**自治体調査で3年 21〜41% 減少しています。**

**製品が今から狙う先としては、縮小中の市場を追うことになります。**

## 6. 本案件への含意

### 6-1. 「置くだけで使える」は、障壁の中心を外している可能性がある

**主要な障壁は「信じてよいか」「効果が読めない」「ルールが作れない」です。**

**これらは操作の簡便さでは解けません。**

### 6-2. ただし「信頼」は、本案件の設計と接点がある

**本案件は次を既に設計しています。**

| 受入基準 | 内容 |
| --- | --- |
| F-002 基準13-2 | **Unicode confusables を検出し、派生物メタデータへ記録する** |
| F-002 基準13-3 | **confusables を自動で置換してはならない** |
| F-003 基準11 | **読み取れなかったファイル・字形の混入が残ったファイルは、その旨を候補へ付記する** |
| F-003 基準10 | **未処理のファイルが1件以上ある場合、その件数を応答へ含める** |

**これらは「どこまで信じてよいかを利用者へ返す」設計です。**

**最大の障壁(出力を信じてよいか)に、偶然ながら接点を持っています。**

**ただし、この接点は企画書にも受入基準の説明にも書かれていません。** **「精度が高い」ではなく「どこが不確かかを示す」ことが訴求になりうる、という整理をしていません。**

### 6-3. 「AI」を名乗らないことについて

**個人調査で「情報漏えい、セキュリティ、安全性に不安がある」は日本 3.8% で、米独の4分の1です。**

**個人においては、セキュリティは障壁として機能していません。**

**一方「使い方がわからない」は 38.6% で独の2.1倍です。**

**この2つを並べると、「安全です」と訴求しても響かず、「何ができるか」を示さないと届かない、という構造が見えます。**

**製品名に AI を入れるかどうかは、本調査では判定できませんでした。** **関連する統計を確認できていません。**

### 唯一の間接材料(根拠の水準は低い)

**原調査報告書 p.164 の有識者ヒアリング(慶應義塾大学 栗原聡教授)。**

> AI は別になくてもよいという意識の人も多く、人工知能が水道やガスと同じぐらい、日常に溶け込んだインフラ化しないと、利用は広がらないのではないか

**きっかけとして「自然言語で指示を出し、UI/UX を意識しなくとも操作できる AI エージェントの出現」を挙げています。**

**ただしこれは統計ではなく単一の有識者の意見です。**

**そして処方箋は「UI を意識させない自然言語エージェント」であって、「既存のファイル操作 UI に載せる」ではありません。** **本案件の仮説と方向が完全には一致しません。**
