# プロセス構成書(未設定)

このプロジェクトのプロセス構成はまだ決まっていません。

## 次にやること

Claude Code でこのリポジトリを開き、次を実行してください。

```
/process-init
```

5つの質問に答えると、このファイルと `process.config.json` が生成されます。

| 質問 | 何を聞くか |
| --- | --- |
| A | 開発に関わる人数 |
| B | プロダクトの段階(PoC / MVP / グロース / 安定運用) |
| C | 品質への要求(一般 / 社会・金銭に影響 / 規制業) |
| D | 開発の形態(自社 / 発注する側 / 受注する側) |
| E | 最悪の場合に何が起きるか(安全重要度) |

専門用語では聞きません。回答から、あなたの状況に合ったゲート構成・成果物・ブランチ保護が導出されます。

## 生成されたあとに読むところ

生成後、このファイルは次の内容に置き換わります。

- **未達のゲート** — 目的を達成する構成を示せていないもの。省略とは区別する
- あなたの状況(回答の言い換え)
- 標準からの差分(全ゲートの適用・簡略化・省略)
- 各判定の理由
- 外せない下限
- CI の設定値
- 構成を変える手順

## 構成が決まる前に

実装を始めないでください。どのゲートを通すかが決まっていない状態では、完了の条件が定まりません。
