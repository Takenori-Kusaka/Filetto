# S0-008 需要側の仮説を検証する — 「外に出せない層は、AI に資料を読ませたいと思っているか」

[S0-007](./S0-007-value-hypothesis.md) と対になる検証です。

**S0-007 は「作れるか・既に誰かが作っていないか」を測りました。本書は「欲しがっている人がいるか」を測ります。**

## 結論を先に

**仮説は弱い。**

**「出せない層が存在する」ことは法令で立証済みです。しかし「その層が AI に資料を読ませたがっている」ことは、確認できた範囲では橋が架かっていません。**

**そして、複数の一次情報が一致して、第3の命題を示しています。**

> **律速段階は「出せない」ではなく「そもそも使い方がわからない/検討していない」である**

| セグメント | 「読ませたい」の根拠 | 判定 |
| --- | --- | --- |
| **自治体** | **総務省の悉皆調査(回答率100%)で RAG 実施 329団体を実測** | **強い。ただし空白は既に埋まっている** |
| 税理士・会計士 | ベンダー自主調査のみ。団体調査は会員限定で非公開 | **弱い** |
| **弁護士** | 団体の一次調査は確認できず | **弱い + 反証あり** |
| 医療 | ベンダー自主調査のみ。理由の数値は非公開 | **弱い** |
| **中小企業** | **8割近くが「そもそも予定なし」**(IPA 一次) | **根拠なし〜反証** |

## 1. 自治体 — 唯一の強い根拠。しかし市場としては最も薄い

**総務省「自治体における生成AI導入状況(令和7年度)」令和8年4月24日**
https://www.soumu.go.jp/main_content/001070295.pdf

**1,788団体へ照会し、1,788団体(100%)から回答。** 令和7年10月31日時点。**悉皆調査です。**

### 仮説を支持する根拠

| 項目 | 実測 |
| --- | --- |
| **カスタマイズ方法(p15)** | **「外部ソースとして業務知識を参照させている(＝RAG)」が 329件で最多** |
| カスタマイズ対象の業務知識(p16) | マニュアル / 議会会議録 / 法令 / FAQ集 / 計画 |
| 活用事例(p5) | **庁内情報の検索 355件** |
| 課題の3位(p8) | **要機密情報流出の懸念がある** |

**導入効果の実例(p6)**

> 議会の想定問答の文案作成／生成AIに過去答弁を反映(**RAG**)させたことで、深夜残業等が減った(中略)150問を超える質問のうち最大96%について活用している(人口5.8万人の自治体)

**「手元の資料を読ませる」という用途が、実測で確認できます。**

### しかし同じ資料が、市場としての空白の不在を示している

| 項目 | 実測 | 意味 |
| --- | --- | --- |
| カスタマイズの有無(p14) | **している 390件 / していない 1,353件** | **読ませているのは少数派** |
| 入力可能な情報資産の機密性(p12) | **最多は「機密性1」654件。「機密性3B」は49件** | **自治体は現に「機密情報は入れさせない」運用。機密を読ませたい需要は自制されている** |
| **導入コスト(p19)** | **「0円」が最多 705件。年間ランニングも「0円」が最多 468件** | **予算が付いていない市場** |
| 導入済サービス上位4位(p9) | QommonsAI / LoGoAIアシスタント / **自治体AI zevo** / exaBase生成AI for 自治体 | **すべて自治体向け＝LGWAN 対応** |
| 活用パターン(p18) | 「専用の生成AI環境を構築」が最下位。「提供元企業のツール」が1,359件で最多 | **自前構築を選んでいない** |

**導入率(p3-4)**: 都道府県・指定都市 **100%**、その他市区町村 **45.6%**。検討中を含め約88%。

### LGWAN 環境の競合は既に存在する

**自治体AI zevo**(https://www.lgsta.jp/zevo/)

> クラウド型サービス(**LGWAN回線で動作**)／職員専用ナレッジAI、過去事業集約AIなど、独自の情報に基づいた回答が可能となる**RAG機能を搭載**

**汎用のオンプレ RAG も存在します。**

| 製品 | 価格 | 導入実績 |
| --- | --- | --- |
| Neuron Enterprise Search(ブレインズテクノロジー) | **月額90,000円〜／買切180万円〜** | 神戸市・秋田県庁 |
| GBaseOnPrem / ジンベイ GenAIオンプレミス / 高知システムズ オンプレミス全文検索AI | — | — |

**自治体セグメントについて、本案件が想定する空白は事実上埋まっています。**

**「需要はある。しかし競合が埋め、しかも金を払わない」** — **最も厳しい組み合わせです。**

**東京弁護士会 LIBRA 2026年6月号 P25-27**
https://www.toben.or.jp/message/libra/pdf/2026_06/P25-27.pdf

- 2025年3月27日「弁護士業務における生成AIサービスの適正利用ガイドライン」施行
- 2025年9月に主要事業者へ照会を実施
- **クラウドの Microsoft 365 Copilot を選定基準5要件に照らして検討した結果**:

> 同選定基準と明らかに齟齬する点は**見当たらなかった**

**業界団体自身が「設定次第でクラウドは使える」という整理に到達しています。**

**「守秘義務があるから外に出せない」という前提が、少なくとも弁護士業界では崩れる方向にあります。**

**なお日弁連の統計・調査ページに、AI・生成AIに関する調査報告書は確認できませんでした。** IT 関連は2017年の特集が最新です。

## 3. 税理士・会計士 — 決定的な一次情報が入手できていない

### 日税連 第7回税理士実態調査(2025-02-21 公表)

https://www.nichizeiren.or.jp/datalibrary/system/survey/250221b/

- 令和6年4月実施、**回答数38,607件・回答率44.8%**
- **AI活用や電子化などの新規項目あり**
- **報告書 PDF は会員限定。直接アクセスで HTTP 401**

**本案件で唯一、入手できれば判定が変わりうる未検証データです。**

### 会計事務所(ベンダー自主調査・二次情報)

**MJS「生成AIの導入・活用に関する実態調査 第2弾」(n=210)**
https://www.accnt.jp/report/2024v2/

| 項目 | 実測 |
| --- | --- |
| 生成AI導入「ある」 | 39%(前回37%) |
| **活用しない理由 1位** | **「どのような生成AIを使用すればよいか分からない」50%** |
| **活用しない理由 2位** | **「生成AIが業務でどのように活用できるか不明」48%** |
| 課題 1位 | データのプライバシーとセキュリティの確保 **55%** |

**注意すべき点があります。**

**「セキュリティが課題」は55%で最多ですが、「活用しない理由」の上位2つはどちらも「わからない」です。**

**懸念としてのセキュリティと、導入を止めている要因は別物です。** **ここを混同すると仮説を過大評価します。**

## 5. 中小企業 — 仮説が成立しない

### IPA『DX動向2025』図表2-10(一次)

https://www.ipa.go.jp/digital/chousa/dx-trend/tbl5kb0000001mn2-att/dx-trend-2025.pdf

> とくに日本の「100人以下」の企業では、「関心はあるがまだ特に予定はない」「今後も取組む予定はない」の割合の合計が**8割近く**となっており、2割強の米国、4割弱のドイツとは大きな差がある

**「出せなくて困っている」のではなく「まだ検討にすら入っていない」のが実態です。**

### 図表2-12(生成AI活用上の課題)

上位は次のとおりです。

1. 生成AIの効果やリスクに関する理解が不足している
2. 適切な利用を管理するためのルールや基準の作成が難しい
3. 誤った回答を信じて業務に利用してしまう
4. 生成AIを活用できそうな業務がない

**本文中に「情報漏えい」「機密」の語は一度も登場しません**(本文・データ集を全文抽出して確認)。

### 図表1-11 の扱いに、追加の注意が要る

**先行調査で「100人以下で DX 専門体制あり 20.7%」を使えるデータとして挙げましたが、母集団に注記があります。**

> **DX への取組の設問で「全社的に」「一部の部門において」「部署ごとに個別で」を選択した企業が対象**

**すでに DX に取り組んでいる企業に限定された母集団です。全中小企業の値ではありません。**

**先行調査の理解より、さらに慎重に扱う必要があります。**

**逆に、性質の異なる3つの調査が同じ結論に収束しています。**

## 7. 判定

### 最も重要な指摘

**「出せない層が存在する」(法令で立証済み)と「その層が読ませたがっている」の間に、確認できた範囲では橋が架かっていません。**

**本案件の仮説はこの2つを接続していますが、複数の一次情報は第3の命題が実際の律速段階であることを一致して示しています。**

> **そもそも使い方がわからない／検討していない**

**本案件の提案が「外に出さずに読ませられます」であるなら、それは顧客が困っている点とずれている可能性が高いです。**

**顧客が困っているのは「何に使えばいいか」であり、その答えを提示できない限り、ローカル完結という特性は購買理由になりません。**

### セグメント別

| セグメント | 判定 |
| --- | --- |
| **自治体** | **需要は実測できる。しかし LGWAN 対応の競合が埋め、導入コストの最頻値が0円。事業機会としては最も薄い** |
| 税理士・会計士 | **「確認できず」であって「根拠がない」ではない。** 日税連の調査が会員限定で入手できていない |
| **弁護士** | **反証がある。** 東弁がクラウドを許容する整理へ到達 |
| 医療 | 利用率63%は二次情報。**「利用しない理由」の数値が非公開** |
| **中小企業** | **仮説が成立しない。** 8割近くが「そもそも予定なし」 |
