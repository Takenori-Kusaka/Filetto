# 用語集

このプロダクトのドメイン用語です。**コードと文書で同じ語を使うため**の辞書であり、一般的な IT 用語の説明ではありません。

エージェントは実装のたびにここを参照します。用語が揺れていると、生成のたびに別の名前が付きます。

## 書き方

| 欄 | 書くこと |
| --- | --- |
| 用語 | 日本語の呼び名 |
| コード上の名前 | クラス名・テーブル名・フィールド名 |
| 定義 | 何を指すか。**何を指さないか**も書く |
| 使わない語 | 同じものを指す別の呼び方。統一のために禁止する |

## 用語

| 用語 | コード上の名前 | 定義 | 使わない語 |
| --- | --- | --- | --- |
| 招待 | `Invite` | 未登録の人へ発行する参加権。登録が完了すると消費される | インビテーション、招待状 |

## 追加のしかた

新しい概念を実装で導入したら、ここへ追加します。**追加は PR 経由**で行い、エージェントが直接コミットする経路は設けません。

同じものに2つの名前が出てきたら、それは用語集の欠落です。片方を「使わない語」へ入れてください。
