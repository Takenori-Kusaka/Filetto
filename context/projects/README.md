# 案件層コンテキスト

案件ごとの文脈です。`<案件ID>.md` として置きます(例: `P-001.md`)。

恒久層(用語集・設計標準・判断記録)と違い、**案件が終われば役目を終えます**。終わったものは `../\_archive/` へ移します。

## 書くこと

| 項目 | 内容 |
| --- | --- |
| 案件の目的 | 企画書の要約。1〜3段落 |
| いま作っているもの | 対象の機能 ID |
| 暗黙の前提 | 要件合意(G-2)で登録したもの |
| 決まっていないこと | 未決の論点。**空欄にしない** |
| 直近の判断 | この案件で採った ADR へのリンク |

## 恒久層へ上げるもの

案件で得た知見のうち、次のものは恒久層へ書き戻します。

- 用語の定義・変更 → `../glossary.md`
- 設計標準・レビュー観点 → `../standards/`
- あとから変えにくい決定 → `../decisions/`

書き戻しは**サイクルの終わりに行います**。「あとでまとめて」は行われません。
