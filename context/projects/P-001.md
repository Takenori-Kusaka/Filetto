# P-001 Filetto

## 案件の目的

個人が自分の PC に 1 コマンド(`docker compose up`)で立てられ、**ファイルを置いた瞬間から人にも AI にも検索可能になる**、維持コストゼロのファイル倉庫を作る。

人向けの入口は Windows Explorer / Google Drive 相当の**ファイル操作が一級市民**の UI(階層・ドラッグ&ドロップ・リネーム・削除・プレビュー)。AI 向けの入口は同一のファイル資産に対する**セマンティック検索と MCP アクセス**。この 2 つが同じ実体を共有していることが本プロダクトの価値であり、既存の RAG 製品(Onyx / AnythingLLM / RAGFlow / OpenDocuments)との差である。既存製品はいずれも「取り込み口」であってエクスプローラーではない。

対象は非エンジニアを含む個人利用者。「AI に読ませたい資料の置き場」を、エンジニアの手を借りずに用意できる状態を最初の成功条件とする。

## いま作っているもの

未着手。機能 ID は G-2 / G-4 を通してから採番する。想定している初期の分割は次のとおり。

| 機能 ID(予定) | 内容 |
| --- | --- |
| F-001 | ファイル操作(一覧・階層・アップロード・DL・リネーム・削除) |
| F-002 | インデクシング(Graphify 連携・状態管理) |
| F-003 | 検索クエリと MCP インターフェース |

## 暗黙の前提

G-2 で正式に登録する。現時点で PO が置いている前提は次のとおり。

| # | 前提 | 崩れたときの影響 |
| --- | --- | --- |
| 1 | Graphify(Apache-2.0)が汎用ドキュメント(PDF・Office 等)に対して実用的な精度で使える | F-002 の実装方針が全面的に変わる。Graphify の主眼はコードベースの AST 解析であり、汎用文書での実力は未検証 |
| 2 | 外部 API・ベクトル DB なしで実用的なセマンティック検索が成立する | 「維持コストゼロ」という中核の訴求が崩れる |
| 3 | 利用者は Docker を起動できる | 「非エンジニアに広げる」という目的と衝突しうる |
| 4 | AGPL-3.0 でも個人セルフホストの採用は妨げられない | 採用が伸びない場合、ライセンス方針の再検討が必要([[ADR-001]] で代替案を記録する) |

## 決まっていないこと

| # | 未決の論点 | 期限 |
| --- | --- | --- |
| 1 | インデクサ抽象化インターフェースの具体的な形(入力・出力・状態遷移) | G-3 まで |
| 2 | JWT クレームの設計。認証基盤は別マイクロサービスとして外出しするが、Filetto 側はクレームでファイルアクセススコープを制御する。どのクレーム名・どの粒度でスコープを表すか | G-3 まで |
| 3 | フロントエンドの実装方式(独自 SPA か、File Browser / Uppy 等の資産活用か) | G-3 まで |
| 4 | 2026年9月公開目標に対する SC-M / SC-P / SC-B の切り分け | G-1 まで |
| 5 | G-6 独立レビューの未達をどう埋めるか(リポジトリ公開によるコミュニティレビュー等) | 初回リリースまで |

## PO が確定させた事項(2026-08-12)

| # | 論点 | 決定 |
| --- | --- | --- |
| A | スコープ | Explorer + 検索の**単体 OSS マイクロサービス**。Auth / User / Chat / LiteLLM / Claude Code はこのリポジトリの対象外 |
| B | ライセンス | **AGPL-3.0** |
| C | 最初のユーザー | **個人が自 PC に Docker で立てる** |
| E | 検索エンジン抽象化 | **インターフェースのみ定義し、実装は Graphify 単一**。1 リポジトリ 1 インデクサとし、混在ケースは初版で非対応と明記する |
| F | 認証 | 認証基盤自体は別の OSS マイクロサービスとして分離。Filetto 側は**JWT クレームによるファイルアクセススコープ制御**を前提に実装する |
| G | 状態通知 | ポーリングによる UI バッジ表示と、SSE/WebSocket によるリアルタイム通知の**両方**を提供する |
| — | 削除の可逆性 | 物理削除ではなく**ゴミ箱方式(復元可能)**とする。リネーム・移動にも元に戻す手段を持たせる。これにより安全重要度を CL0 に下げる |
