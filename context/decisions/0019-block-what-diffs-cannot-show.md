# ADR-0019: 差分に出ないものだけを `permissions.deny` で止める

## ステータス

**採用(2026-08-14)。**

**ADR-0015 決定1 の「`permissions.deny` は空のままとする」を、本 ADR が置き換えます。** **[ADR-0015](0015-enforcement-scope-during-optimization.md) 本文は書き換えません**(`context/decisions/README.md`「採用済みの ADR を書き換えない」)。

## コンテキスト

**2026-08-14、決裁資料を組織の管理外のホスト(`claude.ai`)へ置きました**([#115](https://github.com/Takenori-Kusaka/Filetto/issues/115))。

| 項目 | 値 |
| --- | --- |
| 成果物 | Claude Artifact「Filetto 着手決裁」 |
| ホスト | **`claude.ai`。個人アカウント。エンタープライズ契約ではない** |
| 公開範囲の選択肢 | **「誰でもアクセス可」か「非公開」の2択のみ** |
| 発行前の判定 | **無し** |
| 現状 | **削除済み** |

**起票されるまで、誰も気づきませんでした。**

### なぜ気づかれなかったか

**差分に出なかったためです。**

**本案件の統制は、差分に出るものを G-6 独立レビューで人が見ることを前提に組まれています。** **その G-6 は `unmet` です。** **さらに、外部への発行はそもそも差分に現れません。**

| | ADR-0015 が縮めた遮断 | 本件 |
| --- | --- | --- |
| 対象 | カバレッジ閾値・検査スクリプト・ワークフロー | **外部への発行** |
| **差分に出るか** | **出る** | **出ない** |
| レビューで見えるか | 見える | **見えない** |

**ADR-0015 は「差分に出るものだけ遮断を外す」という線引きでした。** **本件はその線引きの外側にあります。** **同じ決定で扱えません。**

### ADR-0015 決定1 との関係

**ADR-0015 決定1 は「`permissions.deny` は空のままとする」と書いています。**

**2026-08-14、事業決裁者の判断により `deny` へ `Artifact` を入れました。** **したがって決定1 は、その文言のままでは成立しません。**

**本 ADR で置き換えます。** **ADR-0015 の残る決定(2・3・4)は有効です。**

## 決定

### 1. `deny` へ入れる基準は「差分に出るか」

| 差分に出るか | 扱い |
| --- | --- |
| **出る** | **`deny` へ入れない。** 変更は PR に現れ、レビューで見える |
| **出ない** | **`deny` へ入れる。** 見えないものは遮断でしか止まらない |

**「重要かどうか」で決めません。** **重要でも差分に出るなら、レビューで止まります。** **重要でなくても差分に出ないなら、止まりません。**

### 2. 現時点で `deny` に入るのは1件

```
Artifact
```

**エージェントが組織外のホストへ成果物を発行する経路を塞ぎます。**

### 3. 止まらないものを明記する

| 何を止めたいか | 状態 |
| --- | --- |
| リポジトリに組織外ホストへの参照が残ること | **止まる**(`external-host-check`) |
| エージェントが外部へ発行すること | **止まる**(本決定) |
| **人が手で外部へ貼ること** | **止まらない** |

**3行目を消しません。** **止まらないものを書かない統制は、止まっていると誤解させます。**

### 4. ADR-0015 決定4(見直しの時期)は変えない

**遮断範囲の再設計は、G-4 を通過し実装が始まった時点で [#75](https://github.com/Takenori-Kusaka/Filetto/issues/75) として行います。**

**本 ADR は `deny` へ1件入れるだけであり、範囲の再設計ではありません。**

## 検討した選択肢

| 案 | 採らなかった理由 |
| --- | --- |
| **甲 ADR-0015 を書き換える** | **`context/decisions/README.md` が禁じている。** 「書き換えると、当時なぜそう決めたのかが失われます」 |
| **乙 `deny` を空のまま維持し、指示の遵守だけで保つ** | **本件はその方法で1度失敗している。** 発行前の判定を経ず、起票まで気づかれなかった |
| **丙 検査(`external-host-check`)だけで足りるとする** | **検査はリポジトリに残った参照を見つける。** **発行そのものは止めない。** 参照を書かずに発行すれば通過する |
| 丁 `deny` へ外部通信を包括的に入れる | **`WebFetch` / `WebSearch` を含むと調査が止まる。** S0-007〜S0-013 はいずれも外部の一次資料を読んで成立した |

**丙を単独で採らなかった理由が、本 ADR の要点です。** **検査は「残ったもの」を見つけ、遮断は「起こること」を止めます。**

## 可逆性

| 項目 | 内容 |
| --- | --- |
| 後から変えられるか | **変えられる。** `.claude/settings.json` の1行 |
| 変えるとしたら必要なこと | **AI 維持管理者の操作。** `deny` は AI 自身が変えてはならない(`CLAUDE.md` 禁止事項6) |
| いつまでなら安く変えられるか | **いつでも安い。** 実装への依存が無い |

## 非機能への影響

| 項目 | 影響 |
| --- | --- |
| 性能 | 無し |
| 可用性 | 無し |
| **セキュリティ** | **エージェント経由の情報流出の経路が1本塞がる。** **人手の経路は残る** |
| 運用 | **決裁資料を作るとき、Artifact を使えない。** 置き場は `docs/` 配下の Markdown(#115 で確定) |

## 事業への影響

| 項目 | 内容 |
| --- | --- |
| 顕在化が分かる兆候 | **組織外のホストに、組織の資料が残っていることが見つかること** |
| 回復に要する時間 | **削除は即時。** **ただし、いつから誰に見えていたかは確かめられない** |
| 影響を受ける利用者・業務 | **決裁資料・レビュー資料を作るすべての工程** |

## 影響

**この決定によって変わること:**

- **`permissions.deny` が空でなくなる。** ADR-0015 決定1 は本 ADR が置き換える
- **決裁資料は `docs/` 配下の Markdown で作る。** リポジトリの権限が、そのまま配布範囲になる

**トレードオフ:**

- **見た目を失う。** スライド形式の資料は作れない
- **本案件では、決裁資料を4回作り直し、そのうち3回が棄却された。** **最終的に拠り所になったのは正本の Markdown だった**

**この決定で解決しないこと:**

- **人が手で外部へ貼ること。** 遮断はエージェントの操作しか見ていない
- **遮断範囲そのものの再設計**([#75](https://github.com/Takenori-Kusaka/Filetto/issues/75)。`status:on-hold`)
