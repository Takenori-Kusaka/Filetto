# プロダクトの軸

**困ったときに立ち戻る場所です。**

**7つあります。これがすべてです。**

**判断に迷ったら、ここへ戻ります。** **ここが唯一の立ち戻る先です。**

**本書に「案」は書きません。決まったことだけを書きます。**

**採らなかった選択肢と、そこへ至った経緯は、Issue と PR に残ります。** **2026-08-14、判断記録(ADR)のディレクトリを廃しました。** **設計判断の記録は `specs/<機能ID>/spec.md` と `plan.md`、ゲート判定記録、PR へ寄せます。**

---

## 1. 原本のファイルシステムが一級市民

**利用者が置いた場所を、置いたまま実体として扱う。**

**取り込んだコピーを別管理しない。** 派生物は `.filetto/` へ置き、原本ディレクトリへ書き込まない。

**この軸が、既存の RAG 製品との差である。** 12製品の実測で、ファイル監視を実装している製品は0件だった。

---

## 2. 外へ出さない

**実行時の外部通信なし。API キー不要。月額0円。**

**初回のモデル取得だけが例外である。** それも起動時に完了し、抽出の最中には行わない。

**ライセンスは AGPL-3.0。** 外部サービスへ送信する経路を持たない。

---

## 3. 破壊的操作はすべて可逆

**削除・リネーム・移動・上書きは、すべて戻せる。**

**物理削除の API を、WebUI にも MCP にも公開しない。**

**この軸が、安全重要度を CL1 から CL0 へ下げた根拠そのものである。** 失われると、プロセス構成の前提が崩れる。

---

## 4. 確かめる箇所へ1クリックで到達できる

**「不確かさを表示します」で止めない。**

**表示から原文の該当箇所へ到達するまでを、責務に含める。**

**根拠**: 引用元へのクリックは訪問の1%(Chapekis et al., IC2S2 2026)。**確かめる手間を実際に下げた設計だけが判断を改善する**(Vasconcelos et al., CSCW 2023。5実験・N=731)。

**効くかどうかは未検証である。** 企画書の中止条件8 が観測する。

---

## 5. 推測しない。分からないことは、分からないと出す

**この軸は、複数の受入基準に分散している。1つの方針である。**

| 場面 | どうするか |
| --- | --- |
| **紛らわしい文字**(Unicode confusables) | **検出して記録する。自動で置換しない**(F-002 基準13-3。UTS #39 と同じ立場) |
| **原文内の位置が特定できない** | **特定できないことを明示する。推測した位置を返さない**(F-003 基準38) |
| **読み取れなかったファイル** | **読み取れなかったことを結果へ付記する**(F-002 基準26・27 / F-003 基準11) |
| **未処理のファイルがある** | **件数・パス・理由の種別を応答へ含める**(F-003 基準10) |
| 本文が上限を超えて返せない | **署名付き URL へ暗黙に切り替えない。返せないことを明示する**(F-003 基準28) |

**根拠**: 引用があると信頼は上がる。**引用がランダムでも同じ**(Ding et al., AAAI 2025)。**確かめられないまま信頼だけが上がる設計を作らない。**

---

## 6. 運用に依存する値を、ソースコードの定数にしない

**環境変数から読むか、外部の正本から読む。**

**対象**: 保持期間 / 統合比率 / 字形の対応表 / 付記の文言表 / 認可の適用の有無 / 署名付き URL の有効期限 / ローカルポリシーの保管先。

**「増えるもの」を、増えるたびにコードを変える構造にしない。**

---

## 7. 人の入口と AI の入口は、同じ実体を指す

**WebUI と MCP が、同じ保管層の同じファイルを見る。**

**対外へ返す識別子は安定 ID とする。** パスは属性であり、識別子ではない。

**AI エージェントに確認を求めない。** 人に確認を求める UI は、AI が呼ぶ経路に存在しない。だから可逆性を UI ではなく実装で担保する(軸3)。

**本書を書き換える前に、判断記録(ADR)を書く。**

**軸の変更は、受入基準・企画書・決裁の正本のいずれかへ波及する。** 波及先を確かめずに本書だけを直すと、**どれが正しいか分からなくなる。**
